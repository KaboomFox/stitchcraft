StitchCraft

Machine testing protocol

Automated tests prove the files are what we intend. Only a machine proves they sew well. This page is the protocol for machine checkpoints (MC-1 … MC-12) on the reference machine: a Brother PE800, whose 5 × 7 in hoop sews at most 130 × 180 mm. Its 4 × 4 in and small hoops have profiles too, and the TS-10 sheets test them (ADR 0013).

Roles

  • StitchCraft generates each test sheet deterministically: stitch testsheet TS-xx -o TS-xx.pes checks it against the profile of the hoop it is for. It prints that profile, the file’s SHA-256, its size and counts, the threads in the order they are sewn (with the Brother palette name the machine shows for each) and what to check after sewing. Its size and counts are the file’s, read back as the machine reads it. stitch preview TS-xx.pes -o TS-xx.png draws a picture of what the file sews on the reference machine, with the jump threads it leaves. stitch testsheet --list lists the sheets. The MC-1 sheets are drawn stitch by stitch, to test the machine and the file formats; from MC-2, sheets are drawn as designs and planned by the engine, so sewing them tests its stitches, locks and plan assembly too.
  • The tester sews it with the standard setup below, photographs it, measures it, and files a Sew-out report issue (the form asks for everything on this page).
  • A maintainer turns the report into changes: profile values, parameter defaults, new conformance cases, or bugs. Every profile change links its report.

Standard setup (keep it constant)

Record anything that differs in the report.

StabilizerOne layer of medium tear-away; cut-away for knits (TS-09 only)

Bobbin60 wt (90 wt) bobbin thread, white
HoopThe 5 × 7 in hoop, unless the sheet names another; fabric drum-tight, design centred
Machine settingsNote the machine’s speed and its own trim/jump settings (some Brother models trim automatically on long jumps)
StartingHold the thread’s tail for the first few stitches: at MC-1 a tail left loose pulled the first stitches out
Jump threadsThe PE800 cuts the thread at thread changes and stops, but at no jump (MC-1). At each thread change and stop, snip the jump threads sewn so far, and snip the rest before any pull test. The sheets never sew over a jump thread that is still there, but TS-13, which sews its pictures as any design: which jump threads they sew down is one of its checks

Photographing and measuring

  • Front and back, flat, in daylight or a daylight lamp, camera straight above.
  • A ruler in every photo, along the top and left edges, millimetre side visible.
  • Close-ups of anything odd (loops, gaps, puckers, bird’s nests), with the ruler.
  • Measure with a steel ruler or calipers; report in mm with one decimal.
  • Rate each item 1–5 (5 = indistinguishable from expected) and add a sentence.

From report to change

  1. A maintainer reads the report and labels it sewout:pass, sewout:tune or sewout:bug.
  2. Tune: the profile or default changes in a PR that links the report; a conformance case pins the new value; the docs’ parameter pages show the evidence link.
  3. Bug: a failing conformance case reproducing it comes first, then the fix.
  4. Pass: the checkpoint row in ROADMAP.md is ticked with the report link.
