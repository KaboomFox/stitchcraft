# Browser demo

[Open the browser demo](demo/index.html) to try StitchCraft inside VectorCraft.
An empty session opens the Alpine Night starter patch with embroidery effects already applied.

Select a shape and edit its StitchCraft Auto effect in Appearance. For other stitch types,
choose **Effect → Plug-ins**. **Object → Plug-ins → StitchCraft Design Settings** opens the machine
and hoop settings. Download a PES or DST file through **File → Export → Export As…**.

The **Starter & help** panel opens another copy of the patch or downloads its native template.
Save your editable design before closing the tab. The panel's **Documentation** link returns to the docs.

The editor runs in your browser. Its first load downloads a large WebAssembly module and can take
time. The live stitch preview can simplify large areas to keep the editor responsive.

The permanent docs open the published demo. A PR docs preview includes the demo built from that PR.
