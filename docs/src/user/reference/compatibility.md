# VectorCraft compatibility

Which VectorCraft versions the StitchCraft plug-in is tested against, and with what result. The plug-in
arrives with milestone M6, and roadmap step M6.6 writes this page from the
[compatibility gate](../../design/compatibility-gate.md)'s results (`cargo xtask compat report`). Until
then, the gate's daily runs check the VectorCraft versions pinned in `compat/vectorcraft.toml`, and the
repository's Actions tab shows their results.
